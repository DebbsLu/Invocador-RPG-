## ✨ Key Features
- **Interactive Cipher Logic:** Decode hidden text using custom pattern-recognition algorithms built in JavaScript.
- **Multiple Game Modes:**
  - *Decrypt Messages:* Uncover mysterious ancient secrets.
  - *Create & Share:* Encode custom messages to challenge friends.
  - *Auto-Solver Mode:* Input encrypted text to let the algorithm decipher it for you.
- **Immersive Desert Theme:** Dark, mysterious atmosphere with custom typography and thematic styling.
